# APIキーのローカル使用禁止に関するルール（API Usage Rule）

## 重要な原則
- **APIキーを伴うスクリプト（例: `generate.py` や一括処理スクリプト）を、ローカル環境で実行することは厳禁とする。**

## 理由
- Gemini API等の無料枠（Rate Limit）をローカルでのテストや作業で消費してしまうと、本番環境（GitHub Actions等）での自動投稿タスクがエラーとなり、サイトの運用が停止してしまうため。

## 代替手段（エージェントとしての行動指針）
- ローカルのファイルに対して一括処理（リライトや生成）が必要になった場合は、スクリプトを作成して実行させるのではなく、**AIエージェント自身（またはSubagents）の能力とツール（`view_file`, `write_to_file`）を直接駆使して代替処理を行うこと**。
- エージェントは自身のリソースを活用し、ユーザーのAPI無料枠を守る責任がある。
