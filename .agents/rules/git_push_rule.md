# Git Push Policy & PAT Expiration (GitHub PAT)

## 1. 状態のハルシネーション禁止 (No Hallucinating Git Pushes)
- 「プッシュしました」「GitHubと同期しました」と嘘の報告（ハルシネーション）をすることは厳禁です。
- 実際にスクリプト（例: `push_helper.py` やPowerShellコマンド等）を実行し、成功の標準出力を確認するまでは、決して作業が完了したと報告してはいけません。「プッシュできていたはず」「同期されているはず」という推測に基づくやり取りは時間の無駄（ユーザーのフラストレーション）になるため禁止します。

## 2. トークン（GH_PAT）の有効期限 (30 Days Expiration)
- 現在ユーザーが環境変数に設定している GitHub Personal Access Token (`GH_PAT`) は、**2026年8月7日に発行され、30日間のみ有効**（2026年9月6日頃まで）です。
- Gitプッシュ時に 401 Unauthorized などの認証エラーが発生した場合、「トークンの有効期限（30日）が切れた可能性が高い」と即座に判断し、ユーザーにトークンの再発行と環境変数の更新を依頼してください。原因不明のエラーとして無駄な調査を繰り返さないでください。

## 3. プッシュの手順 (Push Procedure)
- ローカルからプッシュを行う際は、安全のため `push_helper.py` などの一時スクリプトを作成して実行し、実行後はスクリプトを削除するなどの方法を推奨します。
